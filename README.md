# Fly Plugin

## Description
Fly Plugin enables players to easily control their flight mode in Minecraft. Players can toggle fly mode, adjust flying speed, set flight durations, and manage who can fly using intuitive commands.

## Features
- Enable/Disable Fly Mode
- Adjustable Fly Speed (1-10)
- Toggle Fly Mode
- Set Flight Duration
- Check Flight Status
- List Flying Players

## Commands
- `/fly add [player]`: Enable fly mode for a player
- `/fly remove [player]`: Disable fly mode for a player
- `/fly list`: List all players currently flying
- `/fly speed [speed]`: Set fly speed (1-10)
- `/fly toggle`: Toggle fly mode for yourself
- `/fly time [minutes]`: Set fly time limit
- `/fly status`: Check your fly status
- `/fly increase`: Increase your fly speed
- `/fly decrease`: Decrease your fly speed

## Installation
1. Download the latest JAR file from the [releases page](https://github.com/your-username/your-repository/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.
